# «Последний пешеход» — Exec-Plan

> Этот план — единственный источник истины по миссии. Блоки отмечаются по мере готовности. Решения и отклонения фиксируются в журнале решений внизу.

## 1. Цель и критерии готовности

**Цель.** Сдать к 14 ноября 23:00 рабочий мини-сайт «Последний пешеход» (Vite + React, GitHub Pages) с реальным сценарием 400–800 слов, шестью AI-иллюстрациями, одним видео 10–20 с, аудио 20–40 с, отчётом с паспортом, экономикой, декларацией ИИ и разделом «Решения и ограничения».

### Definition of Done (по системе баллов)

| Блок баллов | Вес | Что должно быть в сдаче |
|---|---|---|
| Комплект (сценарий + 6 изобр. + видео + аудио + собранный сайт) | 12 | Сайт по ссылке GitHub Pages работает без бэкенда; все 6 иллюстраций, видео 10–20 с, аудио 20–40 с реальные (не плейсхолдеры); сценарий вшит в сцены; обе развилки достижимы |
| Паспорт истории | 2 | В отчёте: название, жанр, аудитория, логлайн, тема, место/время, персонажи, события, эмоция |
| Отчёт | 3 | PDF/док с паспортом, процессом создания, ссылками на мультимедиа |
| Экономика | 2 | Таблица: сервис / число генераций и попыток / кредиты или деньги / время на генерацию, отбор, доработку, монтаж; самые дорогие этапы; альтернативы; допущения |
| Декларация использования ИИ | 1 | По этапам: где ИИ, инструменты, контроль человека, ограничения прав |
| **Итого** | **20** | |
| Бонус: «Решения и ограничения» | +10 | 3–5 решений с обоснованием, 2–3 примера отбора/доработки (с реальными ID ассетов), ограничения сервисов/прав/консистентности/расчётов |

**Общий DoD:** деплой открывается на чистом браузере; `npm run build` зелёный; оба финала проходятся < 5 минут; все требования матрицы §3 закрыты.

## 2. Блоки работ (в порядке выполнения)

> Ассеты генерирует **пользователь** по готовым промптам и складывает в `posledniy-peshehod/src/assets/`. Блок 4 (ожидание/приёмка ассетов) идёт параллельно и **не блокирует** текстовые, отчётные и деплойные блоки.

- [x] **Блок 1. Prompt bible + журнал генераций.** Шаблоны промптов под все ассеты и пустая таблица учёта — чтобы пользователь начал генерировать сразу.
  - Deliverables: `docs/assets/prompts.md` (I-01…I-06, V-01, A-01, портреты; негативные промпты; ID попыток), `docs/assets/log.csv` (схема из брифа §13).
  - Done when: каждый ассет имеет готовый к копипасту EN-промпт + negative prompt; `log.csv` открывается и содержит все колонки схемы.
  - Depends on: —

- [x] **Блок 2. Сценарий и тексты.** Полный сценарий 400–800 слов + производные тексты.
  - Deliverables: `docs/script.md`, `docs/script-captions.md`, `docs/script-tts.txt`.
  - Done when: `script.md` в диапазоне 400–800 слов (посчитать); есть заголовки сцен, фиксированные финальные строки A/B, две подписи выбора дословно из брифа; `script-captions.md` покрывает все реплики радио и шёпот.
  - Depends on: —

- [x] **Блок 3. Вшить реальный текст в данные сцен.** Замена заглушек в коде.
  - Deliverables: `posledniy-peshehod/src/data/scenes.ts` (title/text/choices по сценам 1–5, fork, ending-a, ending-b), `src/data/characters.ts` (имена), `src/App.tsx` (подзаголовок интро, тексты кнопок входа).
  - Done when: `grep` не находит `[СЦЕНА`/`— заглушка` в `src/`; `npm run build` проходит; тексты в UI совпадают со `script.md`.
  - Depends on: Блок 2.

- [x] **Блок 4. Генерация и приёмка ассетов (пользователь).** 6 иллюстраций (I-01…I-06) + 3 портрета (Миро/Радио/Пёс) + видео V-01 (10–20 с) + аудио A-01 (20–40 с), при возможности SFX.
  - Deliverables: файлы в `posledniy-peshehod/src/assets/images/`, `.../video/`, `.../audio/`; запись каждой попытки в `log.csv`.
  - Done when: 6 финальных изображений приняты по правилам (нет лиц, один красный акцент, монохром, без текста), видео 10–20 с, аудио 20–40 с; каждая принятая генерация имеет строку в логе с числом попыток/кредитов/временем.
  - Depends on: Блок 1 (промпты). Идёт параллельно всему остальному.
  - Приоритет генерации: I-01 (style anchor) → I-04 → V-01 → I-05 → I-06 → I-02 → I-03 → портреты → A-01.

- [x] **Блок 5. Интеграция ассетов в сайт.** Подключение медиа и поведение плееров.
  - Deliverables: поля `image`/`video`/`audioCue` в `scenes.ts`, постер для V-01, подписи (captions) для радио, mute, `prefers-reduced-motion` фолбэк.
  - Done when: каждая сцена показывает свой реальный фон (не градиент); V-01 автоплей muted с постером и фолбэком на статичный кадр; аудио стартует по кнопке; субтитры видны при mute; вес медиа < 15 МБ (video < 8 МБ, картинка < 500 КБ).
  - Depends on: Блок 3, Блок 4.

- [x] **Блок 6. Экономика.** Свод таблицы учёта и анализ.
  - Deliverables: раздел экономики в `docs/report.md` по данным `docs/assets/log.csv`; таблица этапов; самые дорогие этапы; сравнение альтернатив; допущения.
  - Done when: в таблице есть все 4 обязательных измерения (число генераций/попыток, кредиты/деньги, время генерации, время отбора/доработки/монтажа); цифры совпадают с логом.
  - Depends on: Блок 4 (нужны реальные данные).

- [x] **Блок 7. Декларация использования ИИ.** Текст декларации по этапам.
  - Deliverables: раздел декларации в `docs/report.md` (инструменты, версии, даты, контроль человека, права).
  - Done when: покрыты все этапы (идея, сценарий, изображения, видео, аудио, код, отчёт); указаны реальные сервисы и число попыток; отмечена синтетическая природа голоса.
  - Depends on: Блок 4.

- [ ] **Блок 8. Деплой на GitHub Pages + QA.** Публикация и проверка.
  - Deliverables: запушенный репозиторий, зелёный workflow `.github/workflows/deploy.yml`, публичная ссылка.
  - Done when: сайт открывается на чистом браузере по Pages-URL; оба финала проходятся; 360 px и 1440 px без горизонтального скролла; Chrome/Safari/Firefox (по возможности iOS); первая загрузка < 3 с.

  - Done when: в отчёте есть паспорт (§1 брифа), сценарий/ссылка, список ассетов, экономика (Блок 6), декларация (Блок 7), раздел «Решения и ограничения» (3–5 решений, 2–3 примера отбора с ID, ограничения); ссылки на сайт и папку рабочих.

## 4. Риски и план Б

| Риск | Вероятность | Что делаем |
|---|---|---|
| **Видео не готово / инструмент не даёт 10–20 с** | высокий | V-01 — обязателен для комплекта, отбросить нельзя. План Б: image-to-video из I-04; если совсем не выходит — сгенерировать 2–3 клипа по 4–6 с и склеить до 12–15 с; крайний фолбэк — медленный панорамный пролёт по I-04, отрендеренный в mp4 (с честной пометкой в ограничениях). |
| **Иллюстрации не все приняты (стиль-дрифт)** | средний | 6 обязательно. Минимум — I-01, I-04, I-05, I-06 (сюжетные), I-02/I-03 добираются последними; I-04 переиспользуется в сценах 4–5 (уже в брифе). Повторная генерация от I-01 как reference. |
| **Аудио не готово** | средний | A-01 обязателен (20–40 с). План Б: сгенерировать чистый эмбиент (wind+drone) без музыки; TTS-голос радио — отдельно. Если аудиосервис недоступен — минимальный трек из одного генератора, довести в редакторе. |
| **Ассеты не успели к дедлайну** | средний | Порядок приоритетов: **видео и 6 картинок обязательны** (комплект 12 б.), аудио обязательно; портреты — желательно (сайт умеет силуэты-заглушки). Плейсхолдеры допустимы только в промежуточной сборке, **в финальную сдачу реальные ассеты обязательны**. |
| **Время: дедлайн 14.11 23:00** | высокий | Параллелить: пользователь генерирует, пока команда пишет сценарий/отчёт/деплой. Деплой делать на ранней сборке (Блок 8 можно запустить до финальных ассетов — обновить повторным push). |
| **Вес медиа > 15 МБ** | средний | Сжимать в WebP/AVIF, видео в H.264/WebM < 8 МБ; проверить перед деплоем. |
| **Свободные триалы кончились** | средний | Малый денежный резерв на топ-ап (по брифу $3–25); приоритет трат — видео. |

**Что важнее при цейтноте:** сначала сюжетные ассеты (I-01, I-04, I-05, I-06) и видео → потом аудио → потом I-02/I-03 и портреты. Текст и сайт готовятся независимо от ассетов.
