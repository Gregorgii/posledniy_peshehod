# Аудио

## Фоновая музыка

Основной трек должен называться строго:

```
theme.mp3
```

Он зацикливается и запускается только после первого действия пользователя (кнопка «Начать»), потому что браузеры блокируют автоплей.

Поддерживаемые форматы: `.mp3`, `.ogg`, `.wav`, `.m4a` (для `theme` ожидается именно `theme.mp3`).

Рекомендации: 1–3 минуты, вес до ~3 МБ, бесшовный луп.

## Аудио-сигналы сцен (one-shot)

Имя файла указывается в `src/data/scenes.ts` в поле `audioCue`, например:

```ts
audioCue: 'cue-radio.mp3',
```

Проигрываются один раз при входе в сцену.

Если аудиофайлов нет — сайт работает без звука, кнопка mute остаётся, ошибок нет.
