# Изображения

Сюда кладутся все статические изображения проекта: фоны сцен, портреты персонажей, постеры для видео.

## Фоны сцен

Имя файла указывается в `src/data/scenes.ts` в поле `image`, например:

```ts
image: 'scene-1.jpg',
```

Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.svg`.

Рекомендации: фактические размеры — сцены 1376×768, портреты 896×1200; вес до ~500 КБ (сжимайте перед добавлением).

Если файла нет или `image: null` — сцена покажет градиентную заглушку и подпись. Сборка не сломается.

## Портреты персонажей

Ожидаемые имена (см. `src/data/characters.ts`):

| Персонаж  | Файл                  |
| --------- | --------------------- |
| Миро      | `char-miro.png`       |
| Радио     | `char-radio.png`      |
| Пёс       | `char-dog.png`        |

Портреты лучше делать с прозрачным фоном (PNG/WebP), расти в полный рост или по пояс, выравнивание — по нижнему краю.

Если портрет не найден — рисуется силуэт-заглушка с именем персонажа.
