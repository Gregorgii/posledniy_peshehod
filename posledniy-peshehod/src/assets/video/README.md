# Видео

Сюда кладутся короткие видео-вставки сцен. Имя файла указывается в `src/data/scenes.ts` в поле `video`, например:

```ts
video: 'scene-4.mp4',
```

Поддерживаемые форматы: `.mp4`, `.webm`, `.ogv`.

Рекомендации:
- `<video autoplay muted loop playsinline>` — без звука, зациклено;
- H.264 / MP4 для максимальной совместимости;
- 1280×720 или 1920×1080, вес до ~3–5 МБ, длительность 10–20 с (факт: 12,79 с);
- постер берётся из фона сцены (`image`).

Если файл не найден или не загрузился — ошибка гасится, показывается постер или плейсхолдер. Сборка не сломается.
